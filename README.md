# AI Creative Studio

AI-powered creative concept generator built with Gemini, HTML, CSS and JavaScript.

## 🚀 Features

- 🤖 AI-powered creative concept generation
- ✨ Professional creative direction
- 🎨 Visual and design recommendations
- 📋 Copy generated concepts
- 📥 Download concepts as TXT
- 📄 Export concepts as PDF
- ✨ Improve existing concepts
- 🔄 Regenerate concepts
- 🖼️ Generate AI image prompts
- 📱 Responsive modern UI

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Node.js
- Express.js
- Google Gemini API
- jsPDF
